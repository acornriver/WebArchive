## ✨ Key Interactions

- **Video-First & Scroll Parallax:** 유튜브 프리뷰가 재생 확인 후 자연스럽게 페이드인되며, 가장자리 소프트 블러(`.depth-frame`)와 1:1 스크롤 수직 시차로 영상과 자막의 깊이감을 분리합니다.
- **Resonance Moiré:** 커서에 반응해 두 개의 동심원 파동이 어긋나며 간섭 무늬를 만드는 경계 없는 Canvas 광학 모아레 조형.
- **Physics Playground:** `matter-js` 기반 물리 엔진 위에서 작업 제목을 잡고 들어 올리면 찝은 지점을 축으로 중력에 의해 축 처지며, 부딪힐 때 Web Audio API 노이즈 사운드가 발생합니다.

## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router, Static Export) · React 19 · TypeScript
- **Styling & Motion:** Tailwind CSS v4 · Framer Motion
- **Interactive & Graphics:** Matter.js · Web Audio API · HTML5 Canvas
- **Content & Assets:** Markdown (`react-markdown`) · Sharp (Responsive WebP Pipeline)
- **Deployment:** GitHub Actions → GitHub Pages (`acornriver.work`)
